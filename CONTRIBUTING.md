# Como contribuir

Obrigada por querer contribuir com o **Metas Diárias para Meninas** 💜

O projeto é propositalmente simples: HTML, CSS e JavaScript puro.

## Formas de ajudar

Você pode:

- relatar bugs;
- sugerir melhorias;
- melhorar acessibilidade;
- melhorar documentação;
- corrigir responsividade;
- propor pequenas funcionalidades.

## Antes de começar

Abra uma Issue para mudanças maiores. Para correções pequenas, pode enviar diretamente uma Pull Request.

## Fluxo sugerido

1. Faça um fork.
2. Crie uma branch.
3. Faça a alteração.
4. Teste desktop e mobile.
5. Faça commits claros.
6. Abra uma Pull Request.

Exemplo:

```bash
git checkout -b fix/nome-da-correcao
```

## Regras do projeto

- manter HTML/CSS/JS puro;
- não adicionar framework sem discussão prévia;
- não adicionar backend sem discussão prévia;
- não adicionar tracking ou analytics;
- não incluir dados pessoais;
- preservar acessibilidade;
- preservar funcionamento local;
- evitar dependências quando a Web Platform já resolver o problema.

## Pull Requests

Explique:

- o que mudou;
- por que a mudança é necessária;
- como testar;
- screenshots, se houver mudança visual.

Mudanças visuais devem respeitar a direção **Lavender Girl**, documentada em `docs/DESIGN.md`, a menos que a alteração de direção seja discutida antes.
