# Changelog

Todas as mudanças importantes deste projeto serão registradas aqui.

## [1.0.0] - 2026-09-07

### Adicionado

- nova identidade **Metas Diárias para Meninas**;
- design **Lavender Girl**;
- barra de progresso;
- histórico recolhível;
- persistência unificada em `metas-diarias`;
- migração de dados das chaves antigas;
- backup e restauração em JSON;
- responsividade mobile;
- melhorias de acessibilidade;
- launcher local para macOS;
- criador de atalho para a Mesa;
- documentação para instalação e contribuições.

### Alterado

- interface anterior escura substituída pela direção Lavender Girl;
- ação **Concluir o dia** agora arquiva o resultado do dia e limpa a lista ativa;
- dados antigos são migrados antes de as chaves legadas serem removidas.
